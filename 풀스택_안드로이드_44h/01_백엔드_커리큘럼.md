## 📊 2026년 7월 기준 스택 판단

| 항목 | 결론 | 근거 |
|------|------|------|
| **JDK** | **Java 25 LTS** (2025.09 릴리즈) | 2026 현재 최신 LTS. Java 26은 non-LTS라 학습용으로 부적합. 채용 공고는 아직 17/21이 많지만 **문법은 상위호환**이라 25로 배우면 다 커버됨 |
| **프레임워크** | **Spring Boot 4.1** (Spring Framework 7 기반, 2026.06) | Spring Boot는 **LTS 지정이 없고** 6개월마다 마이너, OSS 지원 12개월. "최신 안정판을 따라가는 것"이 기본값 |
| **Spring vs Spring Boot** | 논쟁 자체가 무의미 | Boot = Spring + 자동설정 + 내장 서버. **단, IoC/DI/AOP 원리는 Boot에서도 그대로 쓰이고 면접 1순위 단골** |
| **빌드** | **Gradle (Kotlin DSL, `build.gradle.kts`)** | Maven보다 신규 프로젝트 채택률 우위. Kotlin DSL은 안드로이드 트랙과 문법이 겹쳐 **학습 비용이 오히려 줄어듦** ⭐ |
| **DB / ORM** | MySQL 8 + **Spring Data JPA** | 국내 표준 조합 |
| **테스트** | JUnit 5 + **Testcontainers** | H2 인메모리로 테스트하던 시대는 끝. 실제 MySQL 컨테이너를 띄워 테스트하는 게 현재 표준 |

> ⭐ **이 플랜의 숨은 이득**: Gradle Kotlin DSL을 쓰면 백엔드 빌드 스크립트와 안드로이드 빌드 스크립트가 **같은 언어(Kotlin)** 가 됩니다. 3트랙이 서로를 도와주는 첫 지점입니다.

### 2026년에 "새로 추가된" 것들 (기존 24주 플랜에 없던 항목)

- **Virtual Threads (가상 스레드)** — Java 21+ 정식. Spring Boot에서 `spring.threads.virtual.enabled=true` 한 줄로 켜짐. "스레드 풀 튜닝" 지식보다 이게 먼저.
- **레코드 / sealed 인터페이스 / 패턴 매칭 switch** — 모던 Java의 기본 문법. DTO는 이제 `record`로 씁니다.
- **Testcontainers** — 통합 테스트 표준.
- **관측(Observability)** — Micrometer + OpenTelemetry. Actuator로 맛만 봅니다.
- **Spring AI** — LLM 연동 모듈. 32주 안엔 넣지 않지만, 취업 후 첫 학습 대상으로 인지만.

### A단계 — 개발 환경 (1주)
- **JDK 25 LTS** 설치 (Temurin 권장), `JAVA_HOME` 환경변수
- **IntelliJ IDEA Community** + Git + GitHub 계정
- 첫 `main` 실행, IntelliJ 단축키 20개 외우기 (`Shift Shift`, `Alt+Enter`, `Ctrl+Alt+L`, `Ctrl+B`)
- 🛠 GitHub 저장소 생성 → 첫 커밋 → push까지 완주

> 💡 초보자가 여기서 제일 많이 죽습니다. **환경 세팅에 3일 이상 쓰지 마세요.** 안 되면 IntelliJ 번들 JDK 쓰고 넘어갑니다.

### B단계 — Java 기초 문법 (1~2주)
- 변수·자료형(int/long/double/boolean/String), 형변환, 연산자
- `Scanner` 입력, `printf` 출력, String 메서드
- 🛠 BMI 계산기 · 환율 변환기

### C단계 — 제어문 · 배열 · 메서드 (2~3주)
- if/switch(**+ switch expression**), for/while, 향상된 for
- 배열·2차원 배열, 메서드 정의/오버로딩, `static`
- 🛠 구구단 · 성적 통계 · 메뉴형 콘솔 앱(반복 + 조건)

### D단계 — 객체지향 기초 (3~4주)
- 클래스/객체/인스턴스, 필드·메서드, 생성자, `this`
- 캡슐화(private + getter), 패키지, `record`
- 🛠 `Book`, `Member` 클래스 설계 (**Phase 1에서 정한 프로젝트 도메인으로**)

### E단계 — 상속 · 다형성 · 인터페이스 (5~6주)
- `extends`, 오버라이딩, `super`, 업/다운캐스팅
- 추상클래스 vs **인터페이스**, `Object`(equals/hashCode/toString)
- **sealed 인터페이스** (모던 Java)
- 🛠 결제 수단(카드/계좌/포인트) 인터페이스 → 다형성으로 처리

> 🔥 **면접 1순위**: "인터페이스와 추상클래스의 차이", "다형성이 왜 필요한가". 코드로 설명할 수 있어야 합니다.

### F단계 — 예외 처리 (7주)
- try-catch-finally, try-with-resources, throw/throws
- Checked vs Unchecked, **커스텀 예외**
- 🛠 잘못된 입력을 안전하게 처리 + 커스텀 예외 계층 설계

### G단계 — 컬렉션 프레임워크 (7~8주)
- `List/ArrayList/LinkedList`, `Map/HashMap`, `Set/HashSet`
- 내부 동작(배열 기반 vs 노드 기반) — 🧠 CS 자료구조와 직결
- 🛠 회원 관리 콘솔 프로그램 (추가/검색/삭제/정렬)

### H단계 — 제네릭 · 람다 · Stream (9~10주)
- 제네릭 기초, 함수형 인터페이스, 람다
- **Stream API**: filter / map / sorted / collect / groupingBy
- `Optional` 올바른 사용법
- 🛠 컬렉션 데이터를 스트림으로 집계 (for문 버전과 비교해보기)

### I단계 — 모던 Java & 입출력 (11주)
- **record**, **패턴 매칭 switch**, **텍스트 블록**, **var**
- 파일 I/O(`Files`, `BufferedReader`), `LocalDate/LocalDateTime`, enum
- **Virtual Threads 개념** (실습은 Boot에서)
- 🛠 CSV 읽어서 통계 → record로 모델링 → Stream으로 집계

### J단계 — DB & SQL (11~12주)
- RDBMS 개념, MySQL 8 설치, 테이블 설계, DDL/DML
- SELECT / JOIN / GROUP BY / 서브쿼리 / 제약조건 / **인덱스 기초**
- 🛠 프로젝트 도메인의 **ERD를 직접 그리고** 테이블 생성 + CRUD 쿼리 작성

> 💡 ERD는 [dbdiagram.io](https://dbdiagram.io) 로 그립니다. 이 다이어그램이 나중에 포트폴리오 README에 그대로 들어갑니다.

### K단계 — JDBC (13주)
- `DriverManager` → `PreparedStatement` → `ResultSet` 흐름
- 커넥션 풀 개념(HikariCP), SQL 인젝션이 왜 생기는지
- 🛠 **JDBC로 회원 CRUD 직접 구현** (Boot 쓰기 전에 "원래 얼마나 귀찮은지" 체감)

> ⚠️ 이 단계를 건너뛰고 바로 JPA로 가면, JPA가 무엇을 자동화해주는지 평생 모릅니다. **딱 이틀만 고생하세요.**

### L단계 — 웹 기초 (13주)
- HTTP 메서드·상태코드, 요청/응답 구조, 헤더, 쿠키/세션
- 서블릿·MVC 패턴 개념, REST 개념
- 🛠 브라우저 F12 네트워크 탭으로 실제 요청 뜯어보기 + 흐름도 그리기

### M단계 — Spring 핵심 원리 ⭐ (14주)
- **IoC(제어의 역전)**, **DI(의존성 주입)**, Bean, 컨테이너, 싱글톤
- **생성자 주입을 쓰는 이유**(불변·테스트 용이·순환참조 조기 발견)
- 컴포넌트 스캔, `@Component/@Service/@Repository`
- 🛠 **순수 Java로 DI 컨테이너 흉내내기** → "그래서 Spring이 왜 필요한가"를 몸으로 이해

> 🔥 **면접 최빈출 구간**. 여기만 두 번 반복해도 손해 아닙니다.

### N단계 — AOP & 설정 (15주)
- AOP 개념, 프록시, `@Aspect`
- 🛠 모든 서비스 메서드 실행시간을 찍는 로깅 AOP

### O단계 — Spring Boot 4 입문 (15주)
- [start.spring.io](https://start.spring.io) 로 생성 (Gradle-Kotlin, Java 25, Boot 4.x)
- 자동설정 원리, 내장 톰캣, `application.yml`, 프로파일(dev/prod)
- 패키지 구조: `domain / controller / service / repository / dto / config / exception`
- 🛠 `/api/health` 반환하는 첫 API + `curl`로 호출

### P단계 — Web MVC & REST API (16주)
- `@RestController`, `@GetMapping/@PostMapping/@PutMapping/@DeleteMapping`
- `@RequestBody` / `@PathVariable` / `@RequestParam`
- **DTO를 record로** 정의, 계층 분리(Controller ↔ Service ↔ Repository)
- 🛠 메모리 기반 REST API (목록/등록/조회/수정/삭제) + **Swagger UI** 붙이기

### Q단계 — JPA / Hibernate (17주)
- ORM 개념, `@Entity`, 기본키 전략, 필드 매핑
- **영속성 컨텍스트**(1차 캐시·변경 감지·쓰기 지연) ← 면접 단골
- 연관관계(`@ManyToOne`/`@OneToMany`), **지연 로딩 & N+1 문제**
- 🛠 ERD → 엔티티 클래스로 옮기기, `ddl-auto`로 테이블 자동 생성 확인

### R단계 — Spring Data JPA (18주)
- `JpaRepository`, 쿼리 메서드, `@Query`, 페이징(`Pageable`)
- `@Transactional` (전파·읽기전용)
- **N+1 해결**: `fetch join`, `@EntityGraph`
- 🛠 **프로젝트 API 백엔드 완성** (DB 연동 + 페이징 + 검색)

### S단계 — REST 설계 & 예외 처리 (19~20주)
- RESTful URI 규칙, 상태코드 제대로 쓰기(200/201/204/400/401/403/404/409/500)
- `@RestControllerAdvice` + `@ExceptionHandler` 전역 예외 처리
- `@Valid` + Bean Validation, **공통 응답 포맷** 설계
- 🛠 앞서 만든 API를 규칙에 맞게 전면 리팩터링

> 💡 여기서 만든 응답 포맷을 프론트·안드로이드가 **그대로** 파싱합니다. 3트랙이 만나는 지점이라 대충 하면 나중에 세 배로 고칩니다.

### T단계 — 인증 & 보안 (21~22주)
- Spring Security 6/7 필터체인, `SecurityFilterChain` 빈 설정
- BCrypt 비밀번호 해싱, **세션 vs JWT** (왜 앱에는 JWT인가)
- Access/Refresh 토큰, CORS 설정 (프론트 연동 필수)
- 🛠 회원가입/로그인 + JWT 발급 + 인증 필요한 API 보호

### U단계 — 테스트 (23주)
- JUnit 5, AssertJ, `@SpringBootTest` vs 슬라이스 테스트(`@WebMvcTest`, `@DataJpaTest`)
- Mockito 기초, **Testcontainers로 진짜 MySQL 띄워서 통합 테스트**
- 🛠 서비스 계층 단위 테스트 5개 + Repository 통합 테스트 3개

### V단계 — 성능 & 관측 (24주)
- **Virtual Threads 켜보고** 부하 비교, 커넥션 풀 설정
- 인덱스 적용 전/후 실행계획(`EXPLAIN`) 비교
- Actuator + 로깅(SLF4J) 정리
- 🛠 느린 쿼리 하나를 인덱스로 개선하고 **수치를 기록** ← 포트폴리오 최고의 재료

### W단계 — 배포 (25~26주)
- **Dockerfile** 작성 → 이미지 빌드 → `docker compose`로 앱+MySQL 동시 실행
- **AWS EC2 + RDS** 배포, 환경변수/시크릿 분리
- **GitHub Actions** CI (push하면 빌드+테스트 자동 실행)
- 🛠 실제 도메인/IP로 외부에서 API 호출 성공

### X단계 — 통합 프로젝트 (27~30주)
- 웹(Next.js) + 앱(Android) 두 클라이언트를 동시에 받아내는 API로 고도화
- 이미지 업로드(S3), 페이징, 검색, 정렬, 소프트 삭제
- 🛠 **API 문서(Swagger) 링크 하나로 프론트/안드로이드 개발이 가능한 상태**

### Y단계 — 리팩터링 (29~30주)
- 계층 책임 정리, 매직넘버 제거, 중복 제거
- SOLID 관점 셀프 리뷰 (`05_코드작성법.md` 체크리스트 사용)

### Z단계 — 취업 준비 (31~32주)
- 면접 단골: OOP 4대 특성 / DI·IoC / **영속성 컨텍스트** / `@Transactional` 전파 / N+1 / 인덱스 / HTTP / JVM·GC / 스레드 vs 프로세스
- 코딩테스트: 프로그래머스 Lv.1~2 (Java)
- GitHub 정리 + README + 아키텍처 다이어그램 + 기술 블로그

## ✅ 백엔드 완료 기준

- [ ] 상속·다형성·인터페이스를 **코드를 그리며** 설명할 수 있다
- [ ] `record`, Stream, Optional을 자연스럽게 쓴다
- [ ] DI/IoC가 무엇이고 왜 생성자 주입인지 설명할 수 있다
- [ ] JOIN·집계 SQL을 직접 쓰고, 인덱스가 왜 빠른지 B-Tree로 설명한다
- [ ] Spring Boot로 REST API를 백지에서 만들 수 있다
- [ ] 영속성 컨텍스트와 N+1 문제를 설명하고 해결책을 코드로 보인다
- [ ] JWT 인증이 붙어 있고, CORS 설정으로 웹·앱 양쪽이 붙는다
- [ ] Testcontainers 통합 테스트가 CI에서 자동으로 돈다
- [ ] Docker로 컨테이너화해 AWS에 배포되어 **외부에서 호출된다**
